# YOLO Detection App

## Project Goal
- Build a web application for object detection from images and short videos 
using YOLO (Ultralytics), backend FastAPI, frontend React + Vite. Project is 
containerization using Docker, test/deploy automatically via GitHub Actions,
and deploy to cloud (Render).

## Branch Rules
- 'main' is the main branch, which is protected: DO NOT push directly, all the
changes pull MUST be requested.
- Branch's name format: 'feature/<description>' or 'fix/<description>'.
- Each Pull Request need clearly description, meaningful commit message.

## Local Prerequisites
- Linux
- Git configured with GitHub
- Python 3.10+
- Node.js 18+
- Docker & Docker Compose

## Project Structure
- 'backend/' - FastAPI + YOLO
- 'frontend/' - React + Vite
